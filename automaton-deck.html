A new user needs a new OS.

By 2028 there will be about 1.3 billion AI agents at work. Every computer they will use was designed for one person. Automaton is an open-source operating system rebuilt for them: based on Linux, able to run Windows applications, on the machines people already own.

Pre-seed round. I am looking for co-founders.

The models are not the problem.

Two years ago the best model completed 12 % of everyday tasks on a real desktop. The best now completes 86 %, more than a person does. Yet the way the world works has hardly changed.

2

Built when people were the only users.

Operating systems were designed for one kind of user: a person at a screen, with a keyboard and a mouse. AI agents can now operate software as well as people can, but the system has no place for them, so they borrow a person's screen, account and files.

I collected 1,214 public reports, from 721 sources, of agents failing on today's systems and sorted 1,168 of them by cause. Almost none blame the model. They blame the system around it. In my own test, a real agent read a planted secrets file and repeated it 17.4 seconds after it started. Nothing stopped it.

9

Existing apps must keep working.

A new operating system is useless if the programs people already depend on do not run on it. So Automaton must run today's applications from the first day, while new ones are written for it. This is part of stage one and cannot be skipped.

  • Valve has proven the way: 30,065 Windows games now run on its Linux handheld, by reimplementing the Windows interfaces.
  • A small team can do this because AI agents do most of the work of matching how Windows behaves.
  • Measured so far on 697 Windows applications drawn at random. Provisional: two very widely installed titles failed in this run and were fixed afterwards.

Source: SteamDB count of Steam Deck Verified and Playable games, September 2026.

Stage two: the devices people carry.

When the system for the PC is solid, the same system moves to phones, watches and headsets. These are the devices people have with them all day, so an agent there can help with far more of life than one that sits at a desk.

  • The first priority of this stage: every device works smoothly with every other.
  • What we learn about agents on laptops and desktops carries over.
  • Phones and headsets are very different machines, and that will be hard.

Why the incumbents will not.

$123 billion

Their revenue depends on today's design

Apple's services earned that last year, a quarter of the company, much of it from apps sold to people. A system where agents do the work cuts into it. Apple and Google cannot give that up while a new income grows.

1.6 billion

They cannot break what a billion people use

That many devices run Windows, and every change has to leave them all working. So anything new arrives slowly and optional: Microsoft announced Recall, withdrew it within four weeks, and shipped it eleven months later, switched off by default.

430 replies

Their users do not trust them with it

Nearly all hostile, when Microsoft said Windows was becoming an "agentic OS". It later dropped the phrase. "I just want my computer to be a computer." This is why the OS has to be open source: anyone can read what it does.

A new company is a seedling among old trees. It grows in the gaps they leave, where they do not bother to compete, and it earns trust as it grows. By the time it is tall enough to threaten them, it is too late to stop it.

What could go wrong.

Microsoft ships it first

Its version runs on Windows only, is switched off by default, and exists to sell its cloud. Ours is local, works with any model and runs ordinary apps. Its preview proves the need.

A new system never gets applications

We begin as a layer on Linux, where applications already run, and add Windows applications by the route Valve proved. Measured, not promised: slide 10.

Local models are too weak

The demo uses cloud models today. Open models trail the best by about six months. The system works with both, so nothing has to wait for either.

An agent is tricked by what it reads

Each agent has its own account and file layer and sees only what it is given. Its changes wait for its person's approval. An outside security review is in the budget.

Legal questions on compatibility

We reimplement interfaces, as Wine and Proton have done for years. Legal advice comes before any release, and is in the budget.

A very large scope for a small team

Stage one is narrow: one layer and one platform. Agents do most of the building, and the round pays for a team of five.
